# Smart Goal Bot — Дневник продуктивности

Telegram-бот для постановки и отслеживания целей на полгода по SMART с поддержкой частичного прогресса, умной проверкой долгов и отчётами.

## Возможности

- Постановка SMART-цели на 6 месяцев с числовой метрикой
- Разбивка на задачи (день / неделя / месяц)
- **Частичное выполнение**: цель 30 000 → сделал 28 000 → статус «Частично» + процент
- Умная логика: предупреждает, если пытаешься добавить новые задачи при незакрытых старых
- Прогресс-бары, мотивационные сообщения
- Отчёты и индекс продуктивности
- Статусы: Не начато / В процессе / Частично / Выполнено / Не выполнено / Отложено

## Установка и запуск

1. Получи токен у [@BotFather](https://t.me/BotFather)

2. Открой `bot.py` и вставь токен:
```python
BOT_TOKEN = "123456:ABC-DEF..."
```

3. Установи зависимости (если ещё не стоят):
```bash
pip install aiogram aiosqlite apscheduler python-dotenv
```

4. Запусти:
```bash
python bot.py
```

5. Найди своего бота в Telegram и нажми /start

## Основные команды и кнопки

- `/start` — начать
- `/newgoal` — поставить новую цель на полгода
- `🎯 Моя цель` — посмотреть/обновить главную цель
- `📋 Задачи` — список активных задач
- `✅ Отметить прогресс` — быстро обновить задачу
- `➕ Добавить задачу` — новая задача (с проверкой долгов)
- `📊 Отчёт` — статистика и продуктивность

## Как работает частичный прогресс

Пример:
- Цель: заработать 30 000 руб
- Ты вводишь 28 000
- Бот ставит статус 🟨 Частично
- Показывает прогресс-бар: ████████░░ 93%
- Пишет мотивацию: «Почти у цели!»

Галочка «Выполнено» ставится только когда фактическое значение ≥ целевого.
